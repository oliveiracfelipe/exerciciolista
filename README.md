# 🍎 Manipulação de Lista em Python

Um pequeno projeto desenvolvido para praticar conceitos básicos de **listas e estruturas de repetição em Python**.

## 📖 Sobre

O objetivo deste exercício é colocar em prática conceitos fundamentais da linguagem Python, trabalhando com uma lista de frutas e realizando algumas operações sobre ela.

Durante o exercício, são utilizados:

* Criação de listas
* Adição de elementos com `append()`
* Remoção de elementos com `remove()`
* Estrutura de repetição `for`
* Função `len()`
* Exibição de informações no terminal com `print()`

## ✨ O que o programa faz

O programa:

1. Cria uma lista com cinco frutas.
2. Adiciona **Goiaba** à lista.
3. Remove **Maçã** da lista.
4. Percorre a lista utilizando um `for`.
5. Exibe cada fruta no terminal.
6. Mostra a quantidade total de frutas restantes.

## 💻 Código

```python
frutas = ["Maçã", "Pêra", "Laranja", "Uva", "Banana"]

frutas.append("Goiaba")

frutas.remove("Maçã")

for fruta in frutas:
    print(fruta)

print("Sobraram o total de", len(frutas), "Frutas")
```

## 📌 Resultado esperado

```text
Pêra
Laranja
Uva
Banana
Goiaba
Sobraram o total de 5 Frutas
```
